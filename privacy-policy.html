YouTube 채널 분석 크롬 확장

개인정보처리방침

시행일: 2026년 6월 14일  ·  최종 수정: 2026년 6월 14일

YT Analyzer는 유저의 개인 식별 정보를 수집하지 않습니다. 수집하는 모든 데이터는 YouTube 공개 API를 통해 얻은 채널·영상 통계이며, 이를 분석 기능 제공 목적으로만 사용합니다.

1. 수집하는 데이터

데이터 종류 수집 항목 수집 목적 보관 위치
YouTube 공개 데이터 채널명, 구독자 수, 영상 제목, 조회수, 좋아요 수, 댓글 수, 썸네일 URL, 업로드 일시 아웃라이어 분석, 조회수 추이 그래프 제공 Google Cloud Firestore (서버 캐시)
스냅샷 데이터 유저가 방문한 영상의 제목·썸네일·조회수 시점 기록 제목/썸네일 변경 감지 기능 유저 기기 로컬 (chrome.storage.local)
설정 데이터 내 채널 ID, 비교 채널 ID, Pro 활성화 여부, 라이선스 키 대시보드 기능, Pro 인증 유저 기기 로컬 (chrome.storage.sync)
라이선스 검증 Gumroad 라이선스 키 (유저가 직접 입력) Pro 구독 유효성 확인 서버 (검증 결과만 24시간 캐싱)

YouTube 공개 데이터는 YouTube Data API v3를 통해 수집되며, Google의 개인정보처리방침 및 서비스 약관을 따릅니다.

2. 수집하지 않는 데이터

  • 이름, 이메일 주소 등 개인 식별 정보
  • 유저의 시청 기록 또는 검색 기록
  • 위치 정보
  • 결제 정보 (결제는 Gumroad에서 직접 처리, 당사는 라이선스 키만 수신)
  • YouTube 로그인 정보 또는 인증 토큰

3. 데이터 사용 목적

  • 유튜브 영상 및 채널 아웃라이어 분석 결과 표시
  • 조회수 시간 추이 그래프 데이터 수집 및 제공
  • 썸네일·제목 변경 이력 추적 (유저가 방문한 영상에 한함)
  • Pro 라이선스 유효성 검증
  • 서버 캐싱을 통한 응답 속도 개선 및 YouTube API 호출 최소화

수집된 데이터는 위 목적 외의 용도로 사용하지 않으며, 제3자에게 판매하거나 광고 목적으로 사용하지 않습니다.

4. 데이터 보관 및 보안

데이터 보관 위치 보관 기간
채널·영상 통계 캐시 Google Cloud Firestore 최대 6시간 (자동 갱신)
조회수 추이 기록 Google Cloud Firestore 등록 후 최대 90일
라이선스 검증 캐시 Google Cloud Firestore 24시간
스냅샷 기록 유저 기기 영상당 최대 10개, 전체 2MB 한도
설정 데이터 유저 기기 유저가 삭제하거나 확장 제거 시까지

서버는 Google Cloud Platform(asia-northeast3, 서울 리전)에서 운영되며, 전송 중 데이터는 HTTPS/TLS로 암호화됩니다.

5. 제3자 서비스

서비스 용도 개인정보처리방침
YouTube Data API v3 (Google) 채널·영상 공개 통계 조회 policies.google.com/privacy
Google Cloud Firestore 서버 캐시 및 데이터 저장 cloud.google.com/privacy
Gumroad Pro 구독 결제 및 라이선스 키 발급 gumroad.com/privacy

6. 유저의 권리

유저는 다음 권리를 행사할 수 있습니다:

  • 삭제 요청: 서버에 저장된 특정 채널·영상 데이터 삭제 요청
  • 로컬 데이터 삭제: 크롬 확장 제거 시 기기 내 모든 데이터 자동 삭제. 또는 확장 popup → 설정에서 수동 삭제 가능
  • Pro 비활성화: 언제든지 popup 설정에서 라이선스 비활성화 가능

삭제 요청 또는 문의는 아래 연락처로 보내주세요. 요청 접수 후 7일 이내 처리합니다.

7. 어린이 개인정보

YT Analyzer는 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인정보를 의도적으로 수집하지 않습니다.

8. 국제 데이터 이전

서버는 대한민국 서울(Google Cloud asia-northeast3)에 위치하며, YouTube API 호출은 Google의 글로벌 인프라를 경유합니다. 유럽경제지역(EEA) 유저의 데이터는 Google의 표준계약조항(SCC)에 의거해 보호됩니다.
